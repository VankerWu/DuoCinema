# DuoCinema v0.18.0-preview

DuoCinema 是一款为折叠屏交互设计的原创 SwiftUI 视频播放器，支持本地媒体、HTTPS 视频直链以及实验性 WebDAV 多挂载。支持根据设备姿态切换影院布局、播放控制台与动态镜像特效。

### 下载与安装

- **推荐：** 点击仓库 **Code → Download ZIP**，用 Xcode 打开 `DuoCinema.xcodeproj`，使用自己的 Apple 账号在自己的手机上编译签名。
- **IPA：** 仅在此 Release 的 Assets 中确实上传了有效 IPA 后才填写对应文件名。使用 IPA 仍需要适合个人设备的签名/安装方式，并非点击即安装。

### 预览版已知限制

- WebDAV 视频需要先下载到本地缓存，再开始播放。
- 暂不支持 SMB 原生协议挂载、主流云盘原生 OAuth 登录、所有字幕格式及 MKV 全格式解码。
- 部分 Duo 姿态、铰链倒影效果和服务器兼容性可能需要继续调试。

### 安全与版权

请使用自己有权访问的媒体内容及 WebDAV 服务器。DuoCinema 独立开发，未使用其他商业播放器的代码或品牌素材，与 Apple 不存在官方合作关系。
